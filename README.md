# RevenueDot examples

**Runnable sample apps, backends and self-host recipes for [RevenueDot](https://revenuedot.app), the open-source, self-hostable alternative to RevenueCat.**
Same SDK API as RevenueCat, free, and you can run the server yourself. Every example works against a local RevenueDot with the built-in Test Store, so you need no App Store or Google Play account to try it.

> Status: pre-alpha. The catalogue and format are defined in [prd/ecosystem/PRD.md](https://github.com/revenuedot/revenuedot/blob/main/prd/ecosystem/PRD.md). Examples are added as the API stabilises.

## Catalogue (planned)
- **Mobile:** iOS (SwiftUI, UIKit), Android (Compose, Views), React Native (Expo, bare), Flutter, Kotlin Multiplatform, Unity, Capacitor, Cordova, .NET MAUI.
- **Web:** Next.js, React, Vue/Nuxt, SvelteKit, Angular, vanilla JS.
- **Backends (webhook receiver and entitlement check):** Node (Express, Fastify, Hono, NestJS), Next.js, Python (FastAPI, Flask, Django), Go, Rails, Laravel, Spring Boot, Ktor, ASP.NET, Phoenix, axum, Deno, Bun, Cloudflare Workers, Vercel, AWS Lambda, Firebase, Supabase.
- **Migration:** from RevenueCat (one line), Adapty, Qonversion, Superwall, Apphud, raw StoreKit and Play Billing.
- **Self-host:** Docker Compose, Railway, Fly.io, Render, Kubernetes, AWS, Google Cloud Run, Hetzner, Cloudflare.
- **AI:** MCP for Claude, ChatGPT and Cursor; agent skills; scripts an agent can run.

## Every example follows one format
`README.md` (what it is, why RevenueDot, run it, how it works, migrate from RevenueCat, docs) and a header comment in every source file linking to https://revenuedot.app/docs. See the PRD for the exact standard.
